# PrizmCraft

This project is intended to be an open-world sandbox game based on Minecraft for the CASIO PRIZM calculators. These are the FX-CG10, 20, and 50 models.

This **cannot** be installed on the CASIO FX-CG100 (the newest model) due to CASIO removing the ability to install addins.

WIP.

## Working so far

- Rendering blocks
- Flat world generation
- Rendering world
- Camera movement
- Title screen

## Planned

These are features I want to add in the near future to make the game functional.
